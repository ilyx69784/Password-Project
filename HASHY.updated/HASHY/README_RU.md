# HASHY: Password Security & Compliance Auditor

Учебное приложение (Python + Tkinter + SQLite): аудит **вымышленных** хешей паролей
аккаунтов и проверка надёжности пароля по одной общей политике.

> **Каноническая сборка:** поддерживается только эта папка (`HASHY`). Отдельная папка
> `/password` из исходного архива — альтернативный прототип; перенеси её в `archive/`
> или удали.

## Запуск в VS Code (Windows)

1. Python 3.10+ с python.org (`tkinter` и `sqlite3` входят в установку).
2. **File → Open Folder** → папка проекта → **Terminal → New Terminal**.
3. `py main.py` (или двойной щелчок по `run.bat`). Если `py` не найден: `python main.py`.
4. Тесты: `py -m unittest -v`. Должны пройти **47 тестов**. Дополнительные библиотеки не нужны.

## Таблицы (схема v2)

| Таблица | Назначение |
| --- | --- |
| `accounts` | Демо-аккаунты: тип, возраст пароля, хеш, `hash_format`, активность |
| `password_policy` | Мин./макс. длина, энтропия, сложность, макс. возраст, порог блокировки |
| `breach_entries` | Хеш, алгоритм, источник, дата добавления |
| `audit_runs` | Запуски: счётчики по статусам, `inactive_count`, `avg_risk` |
| `audit_results` | Результаты по пользователям + `issue_codes` и `remediation` |
| `strength_checks` | Только энтропия, оценка и число пройденных проверок |
| `settings` | Настройки интерфейса (тема) |

Связь: `audit_runs.id` → `audit_results.run_id`. Версия схемы: `PRAGMA user_version`.

## Старая база данных

Если рядом с `main.py` лежит старый `auditor.db`, при первом запуске он копируется в
`data/auditor.db` и мигрирует на схему v2 (сначала создаётся резервная копия в
`data/backups/`). История сканирований сохраняется.

## Безопасность и ограничения

- **Никогда не вводи реальные пароли** и не сохраняй реальные хеши: база не зашифрована.
- В `strength_checks` пишутся только метаданные; введённый пароль не сохраняется.
- Active Directory, `/etc/shadow` и Have I Been Pwned не подключаются: источники симулированы или импортированы из файлов.
- Строка NIST — подмножество правил SP 800-63B-4, а не сертификация соответствия.
- Энтропия — оценка по набору символов; для паролей, придуманных людьми, она завышена.
